# NFTMintSecure

NFTMintSecure enables secure, decentralized, multi-chain NFT creation through blockchain-based contract execution on a scalable gateway network of nodes.

The key benefits of using NFTMintSecure include:

- NFTMintSecure enables secure, decentralized, multi-chain
- NFT creation through blockchain-based contract
- execution on a scalable gateway

- python
- Modular architecture

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTMintSecure.git`
2. `cd NFTMintSecure`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
